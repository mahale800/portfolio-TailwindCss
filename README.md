# Portfolio — Tailwind CSS

A small, static portfolio page built while learning Tailwind CSS during a five-day DevTown bootcamp.

## What it includes

- Responsive single-page layout with hero, about, projects, and skills sections
- Light/dark theme toggle implemented with Tailwind's class-based dark mode
- Scroll animations powered by AOS
- No build step: the page is a standalone `index.html` file

## Run locally

Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/mahale800/portfolio-TailwindCss.git
cd portfolio-TailwindCss
```

The page loads Tailwind CSS and AOS from public CDNs, so an internet connection is required for those enhancements.

## Repository structure

```text
portfolio-TailwindCss/
└── index.html    # Complete portfolio page
```

This is an early learning project and intentionally keeps the implementation in one file. The copy, project card, and skill list can be adapted as the portfolio grows.
